GOAP Graph Mockups — Empire Gym (45 actions, 4 goals)

Static prototypes exploring how to display a classical-GOAP action dependency graph at scale. Every mockup renders the same data as CkGoapEmpire_Actions.as so differences are purely in layout + interaction.

  • ★ 5. Improved full-app layout (recommended)
    Redesigned window: three-column grid with Plan History rail, center view with redesigned plan strip, and persistent right-side inspector stack (World State · Action Details · Failure Analysis) — no more Action Details as a lost bottom tab.
  • 1. Layered DAG
    Columns = goal-distance depth. Strict left-to-right tiers instead of a free-floating force layout.
  • 2. Radial
    Goal at centre, preconditions radiating outward. Age rings to cut visual noise.
  • 3. Macro-nodes
    Collapse actions into tech-age super-nodes. Click to expand a tier at a time.
  • 4. Dependency matrix
    Actions × effects grid. Sometimes a non-graph view is clearer.

Data source: Plugins/CkTests/Script/CkGoap/CkGoapEmpire_Actions.as
